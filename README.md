# StudentWell

Application intelligente de gestion du budget alimentaire et du bien-être étudiant.

## Description

StudentWell est une application mobile destinée aux étudiants. Elle permet de gérer le budget alimentaire, suivre les dépenses, découvrir des recettes économiques et améliorer les habitudes de vie.

## Technologies utilisées

- React Native
- Expo
- TypeScript
- Supabase

## Installation

1. Cloner le repository :

```bash
git clone https://github.com/noura0014/StudentWell.git
```

2. Accéder au dossier :

```bash
cd StudentWell
```

3. Installer les dépendances :

```bash
npm install
```

4. Configurer les variables d'environnement Supabase dans un fichier `.env`.

5. Lancer l'application :

```bash
npx expo start
```

## Développement

Le projet utilise Expo Router pour la navigation.

Les fichiers principaux de l'application se trouvent dans le dossier `src/app`.
